# 💧 Consumo de Água

## 🎯 Objetivo

O projeto **Consumo de Água** é um sistema desenvolvido em Python para classificar o perfil de consumo de água dos imóveis e emitir alertas educativos aos moradores.

## 🏠 Tipos de imóvel

O sistema trabalha com:
- 🏢 Comercial
- 🏠 Casa
- 🏙️ Apartamento

## 🐍 Tecnologia utilizada

- Python
- GitHub

## ▶️ Como executar

1. Abra o arquivo `app.py`.
2. Execute o programa em um ambiente Python.
3. Informe o tipo de imóvel.
4. Informe o consumo mensal de água em m³.
5. O programa apresentará o alerta correspondente.

## 🌱 Conscientização ambiental

O projeto tem como objetivo incentivar o consumo responsável de água e alertar sobre possíveis desperdícios e vazamentos.
